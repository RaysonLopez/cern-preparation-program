# CERN Preparation Program (Technical & Summer Studentships)

Este repositorio documenta el progreso, ejercicios prácticos y proyectos desarrollados durante el programa de preparación técnica para postulaciones al **CERN** (Organización Europea para la Investigación Nuclear).

---

## 🎯 Objetivo Personal

Desarrollar un portafolio de proyectos prácticos orientados a la resolución de problemas reales, demostrando habilidades en ingeniería de sistemas, infraestructura y análisis de datos para cumplir con los más altos estándares de selección del CERN.

---

## 🛠️ Tecnologías a Fortalecer

- **Lenguajes:** Python, C++
- **Inteligencia Artificial:** Machine Learning
- **Infraestructura & Contenedores:** Docker, Kubernetes
- **Bases de Datos:** PostgreSQL
